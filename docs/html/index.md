# HTML 模块

这里按照 HTML 的核心知识点拆分模块。

## 目录含义

- `base`：HTML 基础标签与文档结构
- `semantic`：语义化标签
- `form`：表单与校验
- `media`：媒体资源与可访问性

## 学习路径建议

- 先看 `base`，掌握文档结构和常见标签
- 再看 `semantic`，理解语义化和 SEO 基础
- 然后看 `form`，补输入控件和表单校验
- 最后看 `media`，整理图片、音视频和无障碍内容
