# Teleport 原理与常见面试题

`Teleport` 的核心不是“跨组件通信”，而是：

`VNode 逻辑层级不变，但真实 DOM 渲染位置被改写。`

最典型场景：

- 弹窗
- 浮层
- 全屏遮罩

这些内容逻辑上属于当前组件，但真实 DOM 往往希望挂到 `body` 或别的容器下，避免样式和层级限制。

## 关键认知

- 组件树关系仍在原位置
- 只是 DOM 插入目标改成了别的容器
- 事件、状态、依赖关系仍按原组件树工作

## 常见面试题

## 1. Teleport 改变了什么？

改变的是 DOM 落点，不是组件逻辑归属。

## 2. 为什么 Teleport 适合弹窗？

因为弹窗逻辑上属于当前组件，但视觉上通常希望脱离当前容器层级，直接挂到更高层容器。
