# 生命周期原理与常见面试题

生命周期如果只背“beforeMount、mounted、beforeUpdate、updated”，很容易答得很死。

更好的理解方式是：

`生命周期不是一组名字，而是组件在不同运行阶段暴露出来的可插入时机。`

也就是说，生命周期的本质是：

- 组件马上要挂载了
- 组件已经挂载了
- 组件马上要更新了
- 组件已经更新了
- 组件马上要卸载了
- 组件已经卸载了

Vue 只是把这些时机变成一组统一 API。

---

## 1. 生命周期为什么需要单独一套机制？

组件运行时内部本来就会经历这些阶段：

1. 实例创建
2. props / slots 初始化
3. render 首次执行
4. DOM 挂载
5. 后续更新
6. 卸载

如果运行时不提供生命周期，用户就没法在“恰当的阶段”插入业务逻辑。

例如：

- 挂载后拿 DOM
- 更新前比较旧值
- 卸载前清理订阅

所以生命周期 API 的存在，本质上是为了：

`把组件内部阶段性时机，暴露成用户可注册的钩子。`

---

## 2. 生命周期在 runtime-core 里是怎么工作的？

主要入口在 `apiLifecycle.ts`。

可以先把它理解成两步：

1. 注册
   把钩子函数挂到当前组件实例的对应数组上
2. 执行
   等 renderer 跑到对应阶段，再把这些钩子取出来执行

也就是说，生命周期 API 本身并不负责“触发时机”，它负责“登记”。

真正的触发时机，掌握在：

- `component.ts`
- `renderer.ts`

这些文件里。

---

## 3. 为什么生命周期必须在 setup 阶段注册？

这是非常常见的面试题。

原因不是“Vue 规定如此”，而是运行时需要知道：

`这个钩子到底属于哪个组件实例？`

在 `setup()` 执行期间，当前活跃实例 `currentInstance` 是明确的。

所以：

- `onMounted(fn)` 调用时
- Vue 能知道“你现在是在给哪个组件注册 mounted 钩子”

如果脱离这个上下文，运行时就失去了归属信息。

所以生命周期注册 API 必须依附于“当前活跃组件实例”。

---

## 4. 生命周期钩子什么时候真正执行？

以 `mounted` 为例：

1. 组件实例创建
2. `setup()` 执行
3. `onMounted(fn)` 被注册
4. render 生成 subTree
5. subTree 被 patch 到宿主环境
6. 组件完成首次挂载
7. renderer 在合适时机执行已登记的 mounted 钩子

所以：

- `onMounted` 的调用时机是 setup 阶段
- `mounted` 回调的执行时机是挂载完成之后

这两个阶段千万不要混淆。

---

## 5. Composition API 生命周期和 Options API 生命周期有什么关系？

本质上它们描述的是同一批运行时阶段，只是入口形式不同。

例如：

- Options API：`mounted() {}`
- Composition API：`onMounted(() => {})`

两者最终都会落到组件实例上的生命周期容器里，然后由 renderer 在对应阶段统一执行。

所以它们不是两套不同生命周期，而是两种注册方式。

---

## 6. 为什么有 before 和 after 两种钩子？

例如：

- `beforeUpdate`
- `updated`

因为这两个时机面对的是不同数据状态：

### beforeUpdate

适合在更新真正落地前做一些读取、对比、准备逻辑。

### updated

适合在 DOM 已经更新完之后做依赖 DOM 结果的逻辑。

所以“before / after”不是命名习惯，而是：

`是否已经完成本阶段主动作` 的区别。

---

## 7. `activated` / `deactivated` 和普通生命周期的区别

这是 KeepAlive 高频追问点。

如果组件被 `KeepAlive` 包裹：

- 切走时不一定真的卸载
- 切回来时也不一定重新挂载

所以普通：

- `mounted`
- `unmounted`

就不够用了。

于是需要额外的：

- `activated`
- `deactivated`

来描述“缓存组件的恢复显示”和“缓存组件的临时离场”。

---

## 8. 常见面试题

## 1. 生命周期的本质是什么？

本质是运行时把组件不同阶段暴露成可注册钩子。

## 2. 为什么生命周期注册 API 必须在 setup 中调用？

因为 setup 阶段才能确定当前钩子属于哪个组件实例。

## 3. `onMounted` 是什么时候注册、什么时候执行的？

- 注册：setup 执行期间
- 执行：组件首次挂载完成之后

## 4. Composition API 生命周期和 Options API 生命周期是什么关系？

它们描述的是同一批运行时阶段，只是注册入口不同。

## 5. `beforeUpdate` 和 `updated` 的核心区别是什么？

前者发生在更新落地前，后者发生在更新完成后。
