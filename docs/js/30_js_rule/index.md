算术运算前必须判断非空，除数必须不为零。禁止出现除零异常。
对undefined和null进行拦截，页面禁止出现undefined，null的显示。
统一拦截后端错误信息，例如参数错误，远程服务异常，服务器错误。未知异常等错误类型不抛给用户。
组件命名规范
hooks规范
ts必须要有明确类型，禁止出现any，非必要不得使用unknown。
ts数据model，方法入参，结果必须要有具体类型。
类型定义区分层次，分为model层，business层，（runtime层）
model层类型和后端接口定义必须保持一致，business层是添加前端业务层添加的一些字段。使用接口继承
model->business  business->model。数据层要有转换函数。
js命名规范：普通变量使用小驼峰，禁止出现拼音和a，b，c，d这种随意命名，避开关键字，变量命名要语义化，要能通过变量名大致推断出这个变量的
含义以及大致的用途。

对于图表例如echarts，所需要的数据，后端要统一返回计算后的结果，保持三端一致
