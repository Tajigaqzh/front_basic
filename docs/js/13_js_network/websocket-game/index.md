# WebSocket 小游戏

这个示例展示一个最小可用的实时同步小游戏：多个浏览器连接到同一个 WebSocket 服务后，可以控制自己的方块在棋盘上移动，所有客户端会看到相同的在线状态。

## 场景

- 每个连接代表一个玩家
- 服务端保存所有玩家的坐标
- 客户端按方向键移动自己的方块
- 任何一次移动都会广播给所有在线客户端

## 目录结构

- `server.js`：HTTP + WebSocket 服务端
- `client.js`：浏览器端逻辑
- `index.html`：界面

## 运行方式

1. 启动 `node server.js`
2. 打开浏览器访问 `http://localhost:3000`
3. 打开多个标签页
4. 使用方向键移动方块

## 学习重点

- WebSocket 的 `Upgrade` 握手
- `ws://` 连接建立
- 二进制协议帧的最小实现思路
- 服务端广播和房间状态同步
