1. 先理解 HTTP 请求和响应的基本结构
2. 再掌握 `fetch`、`XMLHttpRequest`、`axios` 的使用差异
3. 然后学习跨域、Cookie、超时、取消请求等前端常见问题
4. 最后理解 SSE、WebSocket、WebRTC、WebTransport 这些实时通信方案的适用场景
