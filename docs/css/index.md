# CSS 模块

这里按照 CSS 的核心知识点拆分模块。

## 目录含义

- `base`：选择器、优先级、盒模型等基础
- `layout`：定位、Flex、Grid 等布局
- `animation`：动画、过渡、变形
- `responsive`：响应式设计
- `performance`：重排（回流）、重绘、性能优化
- `engineering`：CSS 工程化

## 学习路径建议

- 先看 `base`，打牢 CSS 基础
- 再看 `layout`，解决页面结构与布局问题
- 然后看 `animation` 和 `responsive`
- 最后看 `performance` 和 `engineering`
