# React 模块

这里按照 `docs/react` 目录下的模块语义来整理 React 相关内容。

## 目录含义

- `core`：React 使用
- `api`：API 示例、API 常问到的面试题
- `router`：路由
- `source`：源码
- `zustand`：状态管理扩展
- `rtkq`：数据请求与缓存扩展

## 学习路径建议

- 先看 `core`，补 React 基础使用
- 再看 `api`，整理常用 Hook 和高频面试题
- 然后看 `router`，补路由配置与导航守卫
- 最后看 `source`，深入理解 React 运行机制
- `zustand` 和 `rtkq` 作为项目实战补充
